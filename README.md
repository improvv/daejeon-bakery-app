# 🥐 대전 빵사대
![poster](./assets/poster.png)
> 내 주변 빵집을 쉽고 직관적으로 찾을 수 있는 베이커리 탐색 서비스

<br />

## 📌 About Project
**Bread Map**은 사용자 위치를 기반으로 주변 빵집을 탐색하고,  
검색과 즐겨찾기를 통해 원하는 베이커리를 더 편하게 찾을 수 있도록 만든 서비스입니다.

단순히 위치만 보여주는 지도 앱이 아니라,  
**“어디에 어떤 빵집이 있는지 더 따뜻하고 직관적인 경험으로 탐색할 수 있는 서비스”**를 목표로 했습니다.

사용자는 지도 위에서 주변 빵집을 한눈에 확인할 수 있고,  
현재 위치를 기준으로 가까운 빵집 정보를 빠르게 탐색할 수 있습니다.

<br />

## ✨ Key Features

### 📍 지도 기반 빵집 탐색
- 현재 위치를 중심으로 주변 빵집을 지도에서 확인할 수 있습니다.
- 빵집 위치를 마커로 직관적으로 파악할 수 있습니다.

### 🔎 빵집 검색
- 빵집 이름을 검색해 원하는 매장을 빠르게 찾을 수 있습니다.
- 지도 탐색과 검색 기능을 함께 사용해 더 편리하게 탐색할 수 있습니다.

### 🧭 현재 위치 이동
- 현재 위치 버튼을 통해 사용자의 위치로 지도를 이동할 수 있습니다.
- 현재 위치를 기준으로 주변 빵집을 더욱 쉽게 확인할 수 있습니다.

### ❤️ 즐겨찾기
- 관심 있는 빵집을 저장해 별도로 모아볼 수 있습니다.
- 다시 방문하고 싶은 빵집을 빠르게 확인할 수 있습니다.

### 🥖 가까운 빵집 추천
- 현재 위치를 기준으로 가까운 빵집 리스트를 제공합니다.
- 하단 시트를 통해 주변 빵집 정보를 간편하게 확인할 수 있습니다.

<br />

## 🎨 UI/UX Focus
이 프로젝트에서는 기능 구현뿐만 아니라,  
**빵집 서비스에 어울리는 따뜻한 분위기와 직관적인 사용자 경험**을 만드는 데 집중했습니다.

- 화이트/아이보리 베이스의 깔끔한 화면 구성
- 빵을 연상시키는 따뜻한 포인트 컬러 활용
- 지도, 검색창, 하단 시트, 카드 UI의 일관된 톤앤매너
- 사용자 위치와 빵집 정보를 쉽게 구분할 수 있는 시각적 구조 설계
- 과하지 않으면서도 서비스 정체성이 느껴지는 UI/UX 방향 설정

## 📱 Main Screens

### 1. 메인 지도 화면
- 지도 위에서 주변 빵집을 확인
- 현재 위치 버튼으로 빠른 이동
- 하단 시트에서 가까운 빵집 리스트 제공

### 2. 검색 화면
- 빵집 이름 기반 검색
- 원하는 매장을 빠르게 탐색 가능

### 3. 즐겨찾기 화면
- 저장한 빵집을 별도로 관리
- 다시 방문하고 싶은 빵집을 쉽게 확인 가능

### 4. 빵집 상세 화면
- 빵집 기본 정보 확인
- 평점, 리뷰, 위치 등 핵심 정보 제공
